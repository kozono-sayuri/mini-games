# Sayuri's Mini Games

一個為工作空檔打造的輕量小遊戲館，也是記錄人類與 AI 協作開發過程的作品集專案。

## 目前內容

- 遊戲館入口首頁
- 踩地雷（初級與中級）
- 第一次點擊安全
- 滑鼠右鍵、觸控長按插旗
- 本機最佳時間紀錄
- 響應式版面

## 本機預覽

本專案沒有後端與套件相依，只需要靜態網站伺服器即可預覽。也可以直接透過 GitHub Pages 發布。

## 新增遊戲

1. 在 `src/` 建立遊戲模組。
2. 將遊戲資訊加入 `src/games.js`。
3. 在 `src/app.js` 註冊遊戲路由。
4. 測試鍵盤、滑鼠與觸控操作。

## AI 協作原則

AI 協助產生方案與程式碼；需求定義、工程決策、測試、審查與最終品質由專案擁有者負責。
